🔑 PUNTOS CLAVE
─────────────────────────────────────────────────────────────

1. IDEMPOTENCIA (CRÍTICA en counting-service)
   └─ clientId + upsert en BD = sin duplicados por reintentos

2. OFFLINE-FIRST
   └─ IndexedDB guarda conteos → sync-queue sincroniza al conectar

3. MICROSERVICIOS DESACOPLADOS
   └─ Cada servicio en su propio puerto y BD (si es necesario)

4. ADAPTADOR DE ERP
   └─ Mock → ERPNext → D365 (solo cambiar ERP_PROVIDER env var)

5. PWA INSTALABLE
   └─ Se instala como app nativa en Android/iOS


📊 STACK ELEGIDO
─────────────────────────────────────────────────────────────

Frontend:
  • React 18 + Vite + TypeScript
  • Tailwind CSS + shadcn/ui
  • Dexie.js (IndexedDB)
  • @zxing/browser (escaneo)
  • vite-plugin-pwa (PWA + Service Worker)
  • React Hook Form + Zod

Backend:
  • Node.js 20 LTS
  • NestJS o Express
  • Prisma (ORM)
  • PostgreSQL 16

Infraestructura:
  • Redis (caché + colas)
  • Docker + Docker Compose
  • Nginx (reverse proxy)
  • GitHub Actions (CI/CD)

Testing:
  • Vitest (frontend)
  • Jest + Supertest (backend)
  • Objetivo: 80%+ coverage

📱 PARA EL PORTAFOLIO
─────────────────────────────────────────────────────────────

Descripción en 2 líneas (CV):
  "Aplicación PWA offline-first para conteo de inventario en almacén
   (React, IndexedDB, Service Workers, Node.js). Escaneo de códigos de
   barras, sincronización idempotente, flujo de aprobación y envío de
   ajustes a ERP mediante microservicios."

Tecnologías destacadas:
  ✓ PWA con soporte offline
  ✓ Escaneo de códigos por cámara
  ✓ Microservicios desacoplados
  ✓ Integración ERP (adaptador intercambiable)
  ✓ Sincronización idempotente
  ✓ Dockerización completa
  ✓ CI/CD en GitHub Actions

Diferenciales:
  • Offline-first con sincronización automática
  • Arquitectura hexagonal (adaptadores)
  • Tests con 80%+ coverage
  • PWA instalable en celular


💡 TIPS
─────────────────────────────────────────────────────────────

• Usar branch `develop` para cambios, `main` solo para releases
• Hacer commits pequeños y significativos
• Escribir tests ANTES de implementar (TDD)
• Usar TypeScript en todos los servicios
• No commit de .env, solo .env.example
• Usar eslint + prettier en pre-commit hook
• Grabar video desde celular físico (no emulador)
• Usar mkcert para HTTPS local si necesitas probar cámara
