═══════════════════════════════════════════════════════════════════════════

1️⃣  VERIFICAR PROYECTO LOCALMENTE

   $ cd 05-app-conteo-inventario
   $ git status

   Debe mostrar:
   - Archivos nuevos (sin .env ni node_modules)
   - Nada pendiente de commit


2️⃣  INICIALIZAR GIT (si no existe)

   $ git init
   $ git config user.name "Tu Nombre"
   $ git config user.email "tu@email.com"
   $ git add .
   $ git commit -m "feat: initial commit - Inventory Count PWA v1.0"


3️⃣  CREAR REPOSITORIO EN GITHUB

   - Ir a: https://github.com/new
   - Nombre: inventory-count-pwa
   - Descripción: System for warehouse inventory counting with offline-first PWA
   - Visibility: Public (open-source) o Private
   - NO inicializar con README/LICENSE/gitignore
   - Click "Create repository"


4️⃣  CONECTAR Y PUSH

   $ git remote add origin https://github.com/tu-usuario/inventory-count-pwa.git
   $ git branch -M main
   $ git push -u origin main


5️⃣  CONFIGURAR EN GITHUB

   Settings → Branches:
   - Habilitar branch protection en main
   - Require pull request reviews
   - Require status checks

   About:
   - Agregar topics: inventory, pwa, react, nodejs, offline-first
   - Descripción: System for warehouse inventory counting

🔄 FLUJO DE TRABAJO EN GITHUB
═══════════════════════════════════════════════════════════════════════════

 Para Desarrollar:

   1. Crear rama desde main:
      $ git checkout -b feature/nombre

   2. Hacer cambios + commits:
      $ git add .
      $ git commit -m "feat: descripción"

   3. Push a GitHub:
      $ git push -u origin feature/nombre

   4. Abrir Pull Request en GitHub

   5. Esperar revisión + merge


 Para Issues:

   - Usar plantilla de bug_report.md
   - Usar plantilla de feature_request.md
   - Labels: bug, enhancement, documentation, etc.


 Para PRs:

   - Usar plantilla PULL_REQUEST_TEMPLATE.md
   - Mínimo 80% coverage
   - Todos los tests pasan
   - Revisión aprobada
